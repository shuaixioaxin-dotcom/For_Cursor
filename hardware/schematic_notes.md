## 2. ESP32-S3 最小系统

### 2.1 电源电路

```
USB-C                AMS1117-3.3
  VBUS ──┬──[F1]──┬────┤IN    OUT├──┬──→ 3.3V
         │       │    │         │  │
        C1      C2    │   GND   │ C3,C4
       10uF    100nF  │    │    │ 10uF,100nF
         │       │    └────┼────┘  │
         └───────┴─────────┴───────┴──→ GND

F1: 保险丝 500mA
C1,C2: 输入滤波
C3,C4: 输出滤波
```

## 3. 编码器接口电路

### 3.1 SPI总线连接

```
ESP32-S3                    编码器 (AS5048A示例)
                                 
GPIO11 (MOSI) ──────┬────────────┤ MOSI
                    ├────────────┤ (编码器2-14)
                    │
GPIO12 (SCLK) ──────┼────────────┤ SCLK
                    ├────────────┤ (编码器2-14)
                    │
GPIO13 (MISO) ──────┼────────────┤ MISO
                    ├────────────┤ (编码器2-14)
                    │
GPIO1  (CS0)  ──────┼────────────┤ CS (编码器1)
GPIO2  (CS1)  ──────┼────────────┤ CS (编码器2)
GPIO3  (CS2)  ──────┼────────────┤ CS (编码器3)
...                 │
GPIO17 (CS13) ──────┴────────────┤ CS (编码器14)
```

### 3.2 编码器接口 (每个编码器)

```
ESP32-S3                 编码器模块
                     ┌─────────────┐
  3.3V ──────────────┤ VCC         │
  GND  ──────────────┤ GND         │
  MOSI ──────────────┤ MOSI        │
  MISO ──────────────┤ MISO        │
  SCLK ──────────────┤ SCK         │
  CSx  ──[R100Ω]─────┤ CS          │
                     └─────────────┘

注意: 
- 每个CS线串联100Ω电阻防止瞬态电流
- 长距离连接需加终端电阻和ESD保护
```

### 3.3 编码器连接器 (推荐)

```
14路编码器连接器设计:

方案A: 使用排针 (2.54mm)
  - 每个编码器: 5Pin (VCC, GND, MOSI, MISO, SCLK, CS)
  - 总计: 14 × 2Pin(电源) + 3Pin(SPI共用) + 14Pin(CS) = 45Pin
  
方案B: 使用FPC连接器
  - 灵活连接，适合空间受限场景
  
方案C: 使用DB25/DB37连接器
  - 工业级，牢固可靠
```

## 4. 按键与指示灯

### 4.1 发送按键

```
         3.3V
          │
         [R]10kΩ (上拉)
          │
GPIO0 ────┴────┤S├────GND
              按键

注: GPIO0也是BOOT按键，开发板通常已内置
```

### 4.2 状态LED

```
GPIO48 ────[R]330Ω────┤>├──── GND
                      LED
```

### 4.3 LED状态定义

| LED状态 | 含义 |
|--------|------|
| 熄灭 | 系统空闲 |
| 快闪3次 | WiFi连接成功 |
| 快闪10次 | WiFi连接失败 |
| 常亮 | 数据发送中 |
| 慢闪2次 | 数据发送完成 |

## 5. 可选: CS扩展方案

当GPIO不足时，使用74HC595扩展CS信号：

```
ESP32-S3              74HC595              编码器CS
                   ┌─────────┐
GPIO35 ──────────→ │ DS   Q0 │──────────→ CS0
GPIO36 ──────────→ │ SHCP Q1 │──────────→ CS1  
GPIO37 ──────────→ │ STCP Q2 │──────────→ CS2
3.3V   ──────────→ │ OE   Q3 │──────────→ CS3
3.3V   ──────────→ │ VCC  Q4 │──────────→ CS4
GND    ──────────→ │ GND  Q5 │──────────→ CS5
                   │      Q6 │──────────→ CS6
                   │      Q7 │──────────→ CS7
                   │    Q7S  │──→ 级联到下一片
                   └─────────┘

2片74HC595可提供16个CS信号
```

## 6. PCB设计建议

### 6.1 尺寸估算

| 元件 | 尺寸 (mm) |
|-----|----------|
| ESP32-S3-WROOM-1 | 18 × 25.5 |
| USB-C接口 | 9 × 7 |
| AMS1117 | 8 × 6 |
| 按键 | 6 × 6 |
| 连接器区域 | 50 × 15 |
| **总PCB尺寸** | **约 50 × 50mm** |

### 6.2 布局建议

```
┌────────────────────────────────────────────┐
│  [USB-C]    [BOOT]  [RST]  [LED]          │
│                                            │
│  ┌─────────────────────────┐              │
│  │                         │              │
│  │      ESP32-S3           │   [电源]     │
│  │      WROOM-1            │   [区域]     │
│  │                         │              │
│  └─────────────────────────┘              │
│                                            │
│  ┌────────────────────────────────────┐   │
│  │        编码器连接器 (14路)          │   │
│  └────────────────────────────────────┘   │
└────────────────────────────────────────────┘
```

### 6.3 注意事项

1. **天线区域**: ESP32模块天线区域禁止铺铜和走线
2. **退耦电容**: 每个电源引脚附近放置100nF退耦电容
3. **SPI走线**: 等长设计，避免过长
4. **地平面**: 完整地平面，减少干扰
