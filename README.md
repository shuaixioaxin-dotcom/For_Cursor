# For_Cursor
For testing of Cursor 

## 激光传感器数据解析工具

用于通过串口读取激光传感器数据帧并解析距离和信号强度(AMP)值的Python脚本。

### 帧格式

| 字节 | 内容 | 说明 |
|------|------|------|
| 0 | 0x59 | 帧头 |
| 1 | 0x59 | 帧头 |
| 2 | dis_L | 距离低字节 |
| 3 | dis_H | 距离高字节 |
| 4 | Amp_L | 信号强度低字节 |
| 5 | Amp_H | 信号强度高字节 |
| 6 | Temp_L | 温度低字节 |
| 7 | Temp_H | 温度高字节 |
| 8 | Check_sum | 校验和 |

### 数据计算
- **距离值** = dis_H × 256 + dis_L
- **AMP值** = Amp_H × 256 + Amp_L

### AMP信号强度判断
| AMP范围 | 状态 | 处理方式 |
|---------|------|----------|
| > 400 且 < 65535 | 最佳 ✓ | 保留并显示 |
| 100 ~ 400 | 可接受 | 保留并显示 |
| < 100 | 不可用 | **丢弃，不计算** |

### 安装依赖

```bash
pip install -r requirements.txt
```

### 使用方法

```bash
# 基本使用（Linux默认端口）
python laser_sensor.py

# 指定串口和波特率
python laser_sensor.py -p /dev/ttyUSB0 -b 115200

# Windows系统
python laser_sensor.py -p COM37 -b 115200

# 显示原始帧数据
python laser_sensor.py -p COM37 -r

# 设置显示间隔（秒）
python laser_sensor.py -p COM37 -i 0.1

# 运行测试模式（无需硬件）
python laser_sensor.py --test
```

### 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-p, --port` | 串口号 | `/dev/ttyUSB0` |
| `-b, --baudrate` | 波特率 | `115200` |
| `-r, --raw` | 显示原始帧数据 | 关闭 |
| `-i, --interval` | 显示间隔（秒），0为最快 | `0` |
| `-t, --test` | 测试模式 | 关闭 |
