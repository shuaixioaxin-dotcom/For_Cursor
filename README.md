## 🚀 快速开始

### 方案A：保守优化（推荐）

**文件**: `imu_optimized_conservative.ino`

**特点**：
- ✅ 保持921600波特率（兼容性好）
- ✅ 保持原有寄存器读取（数据完整）
- ✅ 优化超时和输出频率
- ✅ 目标频率：**200-300Hz**
- ✅ 稳定性高，推荐首选

**适用场景**：
- 硬件不确定是否支持更高波特率
- 需要完整的IMU数据
- 追求稳定性

### 方案B：激进优化（高性能）

**文件**: `imu_optimized_aggressive.ino`

**特点**：
- ⚡ 波特率提升到2Mbps
- ⚡ 寄存器数量减半（仅读必要数据）
- ⚡ 极短超时和总线延迟
- ⚡ 目标频率：**400-800Hz**
- ⚠️ 需要硬件支持高波特率

**适用场景**：
- 硬件支持2Mbps波特率
- 只需加速度和四元数数据
- 追求极致性能

## 📝 详细优化说明

### 1. 减少串口输出开销

**原因**：串口输出是最大的性能瓶颈
- 每个周期输出CSV需要约2-3ms
- 这直接限制了最大频率

**优化**：
- 保守版：每5个周期输出1次 → 节省80%输出时间
- 激进版：每10个周期输出1次 → 节省90%输出时间

### 2. 缩短响应超时

**原因**：当IMU通信失败时，30ms超时会严重拖慢整体频率

**优化**：
- 保守版：30ms → 10ms
- 激进版：30ms → 5ms

**注意**：如果网络质量差，可能需要适当增加

### 3. 减少总线延迟

**优化**：
- 总线静默时间：500μs → 200μs/100μs
- TX使能/禁用延迟：90μs → 60μs/30μs

**注意**：过短的延迟可能导致通信错误，需根据硬件调整

### 4. 提高波特率（激进版）

**优化**：921600 → 2000000 baud

**时间节省**：
- 8字节请求：87μs → 40μs
- 47字节响应：510μs → 235μs
- 27字节响应（优化后）：293μs → 135μs

**注意**：
- 需要RS485模块支持2Mbps
- 需要IMU设备支持（可能需要配置）
- 线缆长度越短越好（建议<2米）

### 5. 减少寄存器读取（激进版）

**优化**：22个寄存器 → 11个寄存器

**说明**：
- 只读取加速度（3个寄存器）和四元数（4个寄存器）
- 跳过陀螺仪、磁力计等数据
- 响应从47字节 → 27字节

**注意**：需根据实际IMU寄存器映射调整`parseResponse`中的偏移

## ⚠️ 故障排查

### 频率低于预期

1. **检查CSV输出频率**
   ```cpp
   // 尝试增加divider
   static const uint8_t CSV_OUTPUT_DIVIDER = 20;  // 原来5或10
   ```

2. **检查通信错误率**
   - 如果fail计数很高，说明通信不稳定
   - 降低波特率或增加延迟时间

3. **检查线缆质量**
   - 使用屏蔽双绞线
   - 缩短线缆长度
   - 添加终端电阻（120Ω）

### 通信错误多

1. **增加超时时间**
   ```cpp
   static const uint16_t RESPONSE_TIMEOUT_MS = 15;  // 从5或10增加
   ```

2. **增加总线延迟**
   ```cpp
   static const uint32_t BUS_SILENCE_US = 300;  // 从100或200增加
   ```

3. **降低波特率**
   ```cpp
   static const uint32_t RS485_BAUD = 921600;  // 从2000000降低
   ```

### 数据解析错误

检查寄存器映射（激进版）：

## 📈 进一步优化

如果还需要更高频率：

1. **使用二进制输出格式**
   - 替代CSV文本输出
   - 可节省50%以上输出时间

2. **使用DMA传输**
   - ESP32支持UART DMA
   - 减少CPU占用

3. **多核处理**
   - ESP32双核架构
   - Core 0处理通信，Core 1处理数据

4. **减少IMU数量**
   - 单个IMU可达到更高频率
   - 3个IMU时频率会显著下降

## 📚 参考资料

- **Modbus RTU协议**：每个字符10 bits（1起始+8数据+1停止）
- **RS485时序**：需要适当的DE/RE切换延迟
- **ESP32 UART**：支持高达5Mbps（理论值）
