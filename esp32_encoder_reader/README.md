# ESP32 多摩川编码器高频读取方案

## 项目概述

使用 ESP32 单片机通过 RS485 半双工方式高频读取 6 个多摩川协议编码器数据，并通过 ESP-NOW 无线发送。

## 需求分析

| 参数 | 值 |
|------|-----|
| 编码器数量 | 6 个 |
| 通信协议 | 自定义多摩川协议 |
| 物理层 | RS485 半双工 |
| 波特率 | 2.5 Mbps |
| 命令格式 | 0x50=编码器0, 0x51=编码器1, ... |
| 返回帧长度 | 22 字节 |
| 目标频率 | ≥200 Hz |

## 时序分析

### 单次通信时间计算

```
波特率: 2.5 Mbps = 2,500,000 bps
单位时间: 1/2,500,000 = 0.4 μs/bit

发送命令 (1字节):
  - 10 bits (8数据 + 1起始 + 1停止)
  - 时间: 10 × 0.4 = 4 μs

接收数据 (22字节):
  - 220 bits
  - 时间: 220 × 0.4 = 88 μs

RS485方向切换: ~5-10 μs
编码器响应延迟: ~10-50 μs (取决于编码器)

单次通信总时间: 4 + 10 + 30 + 88 + 10 ≈ 142 μs
```

### 方案对比

| 方案 | 配置 | 单周期时间 | 最大频率 | 200Hz余量 |
|------|------|-----------|---------|----------|
| 方案A | 1路串行×6 | ~852 μs | ~1173 Hz | 5.8倍 |
| 方案B | 3路并行×2 | ~284 μs | ~3521 Hz | 17.6倍 |
| 方案C | 6路并行×1 | ~142 μs | ~7042 Hz | 35.2倍 |

**推荐方案B：3路并行，每路2个编码器**

## 关键实现要点

### 1. UART DMA 配置

ESP32 的 UART 支持 DMA 模式，可以减少 CPU 开销：

- 使用 `uart_driver_install()` 配置 DMA 缓冲区
- 设置适当的接收超时
- 利用 `UART_FIFO_OVF` 和 `UART_BUFFER_FULL` 事件

### 2. RS485 方向控制

```c
// 发送前切换为发送模式
gpio_set_level(RS485_DE_PIN, 1);  // DE=1, RE=1
uart_write_bytes(UART_NUM, cmd, 1);
uart_wait_tx_done(UART_NUM, pdMS_TO_TICKS(1));

// 发送完成后切换为接收模式
gpio_set_level(RS485_DE_PIN, 0);  // DE=0, RE=0
```

### 3. 时序控制

使用高精度定时器确保 200Hz 稳定触发：

```c
esp_timer_create_args_t timer_args = {
    .callback = &encoder_read_callback,
    .arg = NULL,
    .dispatch_method = ESP_TIMER_TASK,
    .name = "encoder_timer"
};
esp_timer_start_periodic(timer, 5000);  // 5ms = 200Hz
```

### 4. ESP-NOW 数据包设计

```c
typedef struct {
    uint32_t timestamp;           // 4 字节
    uint32_t sequence;            // 4 字节
    uint8_t encoder_data[6][22];  // 132 字节
    uint8_t status;               // 1 字节
    uint8_t checksum;             // 1 字节
} __attribute__((packed)) encoder_packet_t;  // 总计 142 字节
```

ESP-NOW 单包最大 250 字节，完全够用。

## 备选方案

### 方案 C：使用 STM32H7

如果需要更高性能或更多 UART：

| 特性 | ESP32-S3 | STM32H743 |
|------|----------|-----------|
| UART数量 | 3 | 8 |
| CPU频率 | 240MHz | 480MHz |
| DMA通道 | 有限 | 丰富 |
| 无线 | 内置WiFi/BLE | 需外接模块 |
| 成本 | 低 | 中等 |

### 方案 D：FPGA + MCU

对于更高要求（如 1kHz+）：

- FPGA 处理多路 UART 并行收发
- MCU 负责数据处理和无线发送
- 可轻松扩展到更多编码器

## 注意事项

### 1. 波特率精度

ESP32 UART 时钟源为 APB_CLK (80MHz)，2.5Mbps 的分频比：
```
分频比 = 80,000,000 / 2,500,000 = 32
实际波特率 = 80,000,000 / 32 = 2,500,000 (精确)
```
✅ 完美支持

### 2. RS485 收发器选型

- 必须支持 2.5Mbps 以上速率
- 推荐：MAX3485, SP3485, SN65HVD75
- 避免：MAX485 (只支持 2.5Mbps 边缘)

### 3. 布线要求

- 485总线使用双绞线
- 终端电阻 120Ω
- 总线长度建议 < 100m (2.5Mbps时)

### 4. 抗干扰

- RS485 收发器加 TVS 保护
- 数字地和模拟地分离
- ESP32 使用独立 3.3V 供电
