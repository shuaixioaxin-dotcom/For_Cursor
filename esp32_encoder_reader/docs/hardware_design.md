### 4.2 布线规则

1. **电源布线**
   - 电源线宽度 ≥ 0.5mm (20mil)
   - 地线宽度 ≥ 0.5mm
   - 使用大面积铺铜

2. **高速信号线 (RS485)**
   - A/B 差分对等长布线
   - 差分阻抗 100-120Ω
   - 避免过孔和锐角

3. **数字信号线**
   - UART信号线宽度 ≥ 0.25mm (10mil)
   - 信号线间距 ≥ 0.25mm
   - 避免与电源线平行走线

4. **天线区域**
   - ESP32-S3天线下方禁止铺铜
   - 天线区域保持净空

## 6. 测试点设计

```
建议预留以下测试点:

1. 电源测试点
   - TP_VIN: 输入电压
   - TP_3V3: 3.3V电源
   - TP_GND: 接地

2. 通信测试点
   - TP_TX1/RX1: UART1 信号
   - TP_TX2/RX2: UART2 信号  
   - TP_TX3/RX3: UART3 信号
   - TP_DE1/DE2/DE3: 方向控制信号
   - TP_A1/B1: RS485-1 总线
   - TP_A2/B2: RS485-2 总线
   - TP_A3/B3: RS485-3 总线

3. 调试测试点
   - TP_TXD0/RXD0: 调试串口
   - TP_EN: 复位信号
   - TP_GPIO0: 启动模式
```
